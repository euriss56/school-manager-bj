# School Manager BJ

**School Manager BJ** est une plateforme numérique de gestion scolaire conçue pour accompagner les établissements dans l'organisation et le suivi de leurs activités.

🌐 **Application en ligne :** https://school-manager-bj.vercel.app/  
💻 **Dépôt GitHub :** https://github.com/euriss56/school-manager-bj

## Présentation

Le projet vise à proposer un espace de gestion scolaire accessible depuis le web, avec une interface pensée pour simplifier les opérations quotidiennes d'un établissement.

## Technologies

- React
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui

## Installation en local

```bash
git clone https://github.com/euriss56/school-manager-bj.git
cd school-manager-bj
npm install
npm run dev
```

## Déploiement

Le projet est configuré pour être déployé sur Vercel.
